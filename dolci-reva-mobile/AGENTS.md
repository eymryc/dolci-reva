# Expo SDK version pinned for this project

This project is intentionally pinned to **Expo SDK 54** (React Native 0.81.5, React 19.1.0), not the latest SDK, per explicit project requirement. Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code, and never run `npx expo install --fix` or upgrade commands without checking the compatibility notes in `CLAUDE.md` first — this project deliberately avoids NativeWind v5 (pre-release) and other bleeding-edge combos for stability.
